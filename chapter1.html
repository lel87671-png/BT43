Chương 1: Tổng Quan & Cấu Trúc Cơ Bản C++

1. Lý thuyết trọng tâm

Cấu trúc một chương trình C++ cơ bản bao gồm khai báo thư viện #include <iostream>, hàm main() là điểm khởi đầu của chương trình, và lệnh std::cout để xuất dữ liệu ra màn hình.

2. Danh sách Bài tập (Từ dễ đến khó)

Bài 1 (Dễ): In câu chào "Hello World"

Viết chương trình C++ in ra màn hình dòng chữ "Hello World!".

Xem lời giải 
#include <iostream>
using namespace std;
int main() {
    cout << "Hello World!";
    return 0;
}

Bài 2 (Trung bình): Tính tổng hai số nguyên

Nhập vào từ bàn phím hai số nguyên a và b, tính và in ra tổng của chúng.

Xem lời giải 
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << "Tong = " << a + b;
    return 0;
}
